## QA review and fixes completed
- Rebuilt the application source as a fresh greenfield tree; old application implementation is not an architectural dependency.
- Split backend ownership by DLD boundaries: foundation auth/audit/files/jobs/crypto/observability and Admin auth/schools/academics/operators/tc/dashboard.
- Enforced opaque server sessions, HMAC token hashing, CSRF, role-plane separation, school/operator state checks and session revocation.
- Made successful login, logout and relevant security audit writes transactional.
- Added protected Next.js server layouts, no-store responses, security headers/CSP and stale-CSRF retry handling.
- Replaced public/base64 branding patterns with bounded private multipart uploads and authenticated preview/remove flows.
- Completed Admin school directory pagination/search/status, school lifecycle, profile/principal branding, academics CRUD/status/order/delete, operator CRUD/status/reset, dashboard and TC screens.
- Hardened school/operator and class/section lifecycle races with transaction locks/rechecks.
- Implemented TC as immutable issuance with unique TC UUID, encrypted frozen snapshot, branding hashes, trusted `{jobId}` queue payload, idempotent worker state and retry-safe rendering.
- Preserved issued-TC branding immutability across later logo/signature replacement.
- Ensured terminal worker failures are audited and retryable failures return authoritative DB state to QUEUED.
- Kept MOD-003 deliberately absent; MOD-001 student capability is an explicit fail-closed port until MOD-003 implements `StudentsPublicFacade`.
- Removed TODO/FIXME/placeholder production paths from the delivered scope.
