# FB-02 — School UDISE, School Code and Affiliation Number fields

**Source:** DOCX page 1.. **Work status:** [single tracker](../TASK-TRACKER.md). **Approval required:** update Harness authority before implementation. **Current code / owner:** prisma School model; SchoolsService.create/update/get; admin school profile/edit DTO and UI.

## Business goal, concrete use cases and acceptance
**User story:** As platform administrator, I enter the school's official identifiers once at the school level, without asking each student to enter the school UDISE again.

**Use cases and expected results:** UC1: new school stores UDISE 00001234567 and displays its leading zeroes. UC2: existing school adds affiliation number without overwriting principal. UC3: school with absent identifiers continues using current ERP while profile shows missing values. UC4: wrong tenant cannot edit another school.

**Business policy and acceptance rules:** Codes are school-level strings; preserve leading zeroes/case where relevant. Optional until client confirms mandatory status/validation and jurisdiction; no unapproved format constraints. Apply optimistic school version to edits and audit who changed identifiers.

## Detailed Level Design (proposed until approved)
**DB schema, indexes and migration/backfill:** Add nullable School.udiseNumber varchar(32), schoolCode varchar(64), affiliationNumber varchar(64) with CHECK length by validator, no blanket unique until approved; migrate additive. Preserve School.id UUID; no relation to old Student.udiseCode except deprecation FB-03.

**API/routes/contracts, validation and authorization:** Extend existing POST/PATCH/GET /platform/schools and school detail DTOs, Zod inputs; expose safe school identity read facade to Students print/TC document owners. PATCH requires {version}; on stale return 409.

**Frontend screens, backend service orchestration, ports/facades and processing algorithm:** Admin school create/profile form labeled 'School UDISE Number', 'School Code', 'Affiliation Number'; ability to clear/save; normalized trimmed inputs with no numeric coercion; document consumers use frozen issuance snapshot, not dynamic lookup each print.

**Errors, edge cases, reconciliation and recovery design:** Legacy tenants lacking values should render em dash, not invented defaults. School identifiers are business codes not hard security IDs; use UUID for authorization.
