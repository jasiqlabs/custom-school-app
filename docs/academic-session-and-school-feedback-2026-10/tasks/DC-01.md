# DC-01 — Transfer Certificate issuance in school operator panel

**Source:** Client fee and document feedback, and PDF academic clarification 4. **Current baseline:** TC lives at `apps/api/src/modules/platform-admin/tc/tc.service.ts` and is currently available through platform-admin routes only. Operator path is a requested scope amendment to the approved PRD. Task delivery status is maintained only in `../TASK-TRACKER.md`.

## Business requirement and use cases
A full school manager can search own students, preview official TC, generate an encrypted-snapshot TC PDF, monitor the job, download existing issuances, and retry failed renders. A report-only operator cannot issue. Existing platform-admin TC remains operational and must obey the same approved financial-clearance policy. Missing logo or principal signature results in actionable readiness error. Issuing TC does not automatically mark student LEFT until PDF clarification 4 is answered.

## Proposed DLD
Reuse `TcService`, `TransferCertificate`, `Job`, `SchoolFile` and existing encrypted frozen snapshots. Introduce `TcPublicFacade` on TC owning module and an operator-facing controller consuming it via composition binding, without directly accessing another module's Prisma repository. New proposed routes under `/operator/transfer-certificates`: GET list, POST issue, GET `:id`, GET `:id/download`, POST `:id/retry-render`. Operator `schoolId` must come from verified session, never request body. Document actor type must use actual OPERATOR or PLATFORM_ADMIN in job and audit metadata; not hardcoded to PLATFORM_ADMIN. Snapshot includes school identity FB-03, academic-session class AS-03, template version and fees clearance decision DC-02. Store jobs as `{jobId}` only and rehydrate secure state in worker. Support idempotency token for same client request while deliberate reissuance remains a new document. UI operator page has student search, readiness, issue confirm, status list, safe download and retry. Old `/platform/schools/:id/transfer-certificates` routes remain compatible.
