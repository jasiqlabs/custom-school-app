# DC-05 — Versioned, auditable and immutable document lifecycle

**Source:** Cross-cutting design identified from approved TC flow and new receipt/admit requests. **Status:** [one tracker](../TASK-TRACKER.md).

## Requirement and scenarios

Every issued TC, receipt and approved Admit Card is reliable, tenant-secure, downloadable and historically reproducible; reprint is not the same as creating a new issuance.

- **UC-01:** Principal details changed since TC issued; prior immutable TC PDF still reflects old school state.
- **UC-02:** PDF worker failed due to transient storage; retry renders from SAME snapshot and checksum.
- **UC-03:** Operator downgraded after issue cannot retrieve file with stale session.
- **UC-04:** Receipt later voided, original payment and receipt identity retained; show VOIDED annotation without erasing financial audit.
- **UC-05:** Upgrade PDF renderer to standard-v2 with school codes; standard-v1 remains readable.

## In-depth DLD

**Aggregate ownership:** Existing TC owner keeps TransferCertificate/TC snapshot and document job; Fees owner owns fee receipt immutable financial projection; AdmitCard owner (if paid CR approved) owns admit card. Shared infrastructure manages private files, crypto, rendering job primitives only. Avoid creating a second mutable master document table duplicating ownership; use optional `DocumentManifest` read model linked to domain-issued records if a combined list is approved.

**Schema proposal:** optional manifest `(id UUID,schoolId,domainDocumentType,domainReferenceId,studentId?,academicSessionId?,templateVersion,issuerType,issuerId,issuedAt,snapshotChecksum,contentChecksum?,fileId?,jobId?,status QUEUED|PROCESSING|COMPLETED|FAILED,attemptCount,lastFailureCode,version)`, uniqueness `(schoolId,domainDocumentType,domainReferenceId,templateVersion)`; tenant-scoped FK/indices. Encrypted issue snapshots remain in owning aggregate with crypto keyVersion, IV/tag. File service holds bucket/objectKey private, sha256 and integrity state.

**API:** Owning-domain GET issued document/status/download, POST retry-render if FAILED and capability allows; short-lived signed private URL issued only AFTER actor role, school and domain relationship check; `Cache-Control: private,no-store` and typed 404/403/409. Optional read-only aggregated `/operator/documents` only after product approval.

**Rendering:** Job creation and audit outbox transaction; BullMQ payload only `{jobId}`; worker loads document record and frozen snapshot from DB, checks authorized job state, loads logo/signature through private file service, renders versioned PDF, calculates SHA256, stores private file, updates state exactly once. On crash mark lease expired then retry bounded, never reuse a new latest-student snapshot. For old v1 PDF downloads, preserve original file as issued even if new renderer available. Revoked/void marking handled as new event/annotated view where explicitly required.

**Security:** No Aadhaar by default in document outputs, logs or queue. Encryption key rotation must retain decryptability of old key versions; no public bucket access. Prevent IDOR by role and school, rate limit downloads, safe filename/content disposition and PDF injection sanitization.

**UI:** Status QUEUED/PROCESSING/COMPLETED/FAILED, error code and retry if recoverable, reprint vs new issue distinctly labeled, last-issued/time/issuer, disabled controls when role revoked. Print A4/Unicode ₹ and school IDs; prevent page clipping.

## Named test specification

**FE:** DC05-FE01 old/new print snapshot and headers; FE02 status polling + retries; FE03 expired download button refresh; FE04 void watermark; FE05 responsive and accessible PDF viewing.
**BE:** DC05-BE01 frozen snapshot checksum immutable, BE02 duplicate job replay no duplicate issuance, BE03 tenant and role BOLA, BE04 old v1 render/download, BE05 corrupted file checks, BE06 user role downgrade while job in queue, BE07 encryption key rotation.
**NFR:** DC05-NFR01 50 simultaneous signed downloads, DC05-NFR02 100 queued PDFs and worker restart, DC05-NFR03 >=7-year retention and backup/restore rehearsal, DC05-NFR04 PDF visual goldens and text extraction, DC05-NFR05 no PII in logs/job payload.

## Release gate

Keep prior TC and receipts intact. Paid Admit Card scope remains separately blocked. Only mark DONE after independent evidence in one tracker plus careful migration/rollout plan.
